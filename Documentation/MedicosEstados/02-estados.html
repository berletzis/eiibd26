Máquina de estados propuesta — Profesional

Estados del registro del profesional (derivados de campos existentes)

No se agrega un nuevo campo EstadoProfesional a la BD. El estado se deriva en tiempo de ejecución desde los campos existentes. Esto evita migraciones complejas y mantiene la fuente de verdad distribuida en campos bien definidos.

Función canónica — DerivarEstadoProfesional()

Esta función reemplaza toda lógica dispersa. Todas las pantallas la consumen.

// En MedicoDirectorio (NotMapped) o en un helper estático

public enum EstadoProfesionalDerivado
{
    Propuesto        = 0,  // Activo=false, VisiblePublicamente=false
    CedulaVerificada = 1,  // EstatusValidacion=Validado (aún no publicado)
    Publicado        = 2,  // Activo=true, VisiblePublicamente=true
    Reclamado        = 3,  // EstatusReclamacion=Reclamado (+ publicado)
    Eliminado        = -1  // Eliminado=true
}

[NotMapped]
public EstadoProfesionalDerivado EstadoDerivado
{
    get
    {
        if (Eliminado)                                           return EstadoProfesionalDerivado.Eliminado;
        if (Activo && VisiblePublicamente
            && EstatusReclamacion == EstatusReclamacion.Reclamado) return EstadoProfesionalDerivado.Reclamado;
        if (Activo && VisiblePublicamente)                       return EstadoProfesionalDerivado.Publicado;
        if (EstatusValidacion == EstatusValidacionCedula.Validado) return EstadoProfesionalDerivado.CedulaVerificada;
        return EstadoProfesionalDerivado.Propuesto;
    }
}

Unificación de "Verificado" — Una sola verdad

Regla canónica: EstatusValidacion es la única fuente

La fuente de verdad para "cédula verificada" es únicamente MedicoDirectorio.EstatusValidacion.

El badge "verificado" en MedicoPerfilBadge debe ser un efecto secundario automático de cambiar EstatusValidacion.

Cambio en OnPostEditarAsync — sincronización automática de badge

// En Admin/DirectorioMedicos/Index.cshtml.cs
// ANTES:
if (cambioVerificacion)
{
    if (cedulaVerificada) { medico.EstatusValidacion = EstatusValidacionCedula.Validado; medico.FechaCedulaVerificada = DateTime.UtcNow; }
    else { medico.EstatusValidacion = EstatusValidacionCedula.PendienteValidacion; medico.FechaCedulaVerificada = null; }

// DESPUÉS (agregar sincronización de badge):
if (cambioVerificacion)
{
    if (cedulaVerificada)
    {

        medico.FechaCedulaVerificada = DateTime.UtcNow;

        medico.FechaCedulaVerificada = null;
        await _badgeService.RevocarBadgeAsync(medico.Id, "verificado");           // ← NUEVO
    }
}

Mismo fix para OnPostVerificarAsync (handler de toggle rápido)

public async Task<IActionResult> OnPostVerificarAsync()
{
    var id = int.Parse(Request.Form["id"]!);
    var m  = await _db.MedicosDirectorio.FirstOrDefaultAsync(x => x.Id == id);
    if (m is null) return new JsonResult(new { success = false });

    var toggleVerificado = m.EstatusValidacion != EstatusValidacionCedula.Validado;
    m.EstatusValidacion     = toggleVerificado ? EstatusValidacionCedula.Validado : EstatusValidacionCedula.PendienteValidacion;
    m.FechaCedulaVerificada = toggleVerificado ? DateTime.UtcNow : null;
    m.FechaModificacion     = DateTimeOffset.UtcNow;
    await _db.SaveChangesAsync();

    // Sincronizar badge "verificado" — FUENTE CANÓNICA
    if (toggleVerificado)
        await _badgeService.OtorgarBadgeAsync(m.Id, "verificado", "admin");
    else
        await _badgeService.RevocarBadgeAsync(m.Id, "verificado");

    await RecalcularNivelAsync(m, id);
    return new JsonResult(new { success = true });
}

Eliminación de lógica duplicada en el Admin panel

Tri-badges del Admin grid — unificar con EstadoDerivado

Actualmente la función JavaScript triBadges(row) en el Admin grid calcula:

const comunidadOk = d.totalConfirmaciones >= 3 && d.tieneConfirmacionEII;
const verificadoOk = d.cedulaVerificada || d.totalConfirmaciones >= 5;  // ← lógica diferente
const reclamadoOk  = d.perfilReclamado;

La condición verificadoOk mezcla cédula verificada con confirmaciones — no corresponde al badge real. Debe simplificarse:

// CORRECCIÓN:
const comunidadOk = row.totalConfirmaciones >= 3;
const verificadoOk = row.cedulaVerificada;   // ← solo la fuente canónica
const reclamadoOk  = row.perfilReclamado;

// El servidor ya devuelve:
// row.cedulaVerificada = (EstatusValidacion == Validado)
// row.perfilReclamado  = (EstatusReclamacion == Reclamado)
