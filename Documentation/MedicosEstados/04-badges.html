El problema: lógica de badges en 3 lugares distintos

Situación actual — 3 fuentes distintas que definen los mismos badges:
  1. Panel Admin superior — usa comunidadOk, verificadoOk, reclamadoOk calculados desde datos del JSON
  2. Panel Admin sección Badges — lee MedicoPerfilBadge de BD directamente
  3. Card pública / Detalle público — combina NivelConfianza con BadgesGanados (HashSet de strings)

El resultado: los 3 lugares pueden mostrar estados diferentes para el mismo profesional.

Solución: IMedicoBadgeService como única fuente

Fix BUG-3: Sincronizar badge "verificado" con EstatusValidacion

El cambio clave: el badge "verificado" pasa de ser manual puro a ser automático condicionado — se otorga cuando admin marca la cédula como verificada, y se revoca cuando la desmarca. El admin puede seguir viéndolo en el panel de badges pero no puede otorgarlo/revocarlo desde ahí — solo a través del campo de cédula.
Cambio en la renderización del panel de badges

En el JSON que devuelve OnGetMedicoAsync, el badge "verificado" actualmente aparece como esManual=true, lo que muestra botones de otorgar/revocar en el UI. Debe cambiarse:

// ANTES en OnGetMedicoAsync:
var badgesData = catalogo.Select(b => {
    var ganado = ganadosIds.FirstOrDefault(g => g.BadgeId == b.Id);
    return new {
        ...
        esManual = b.Codigo == "verificado" || b.Codigo == "creador_contenido"  // verificado era manual
    };
}).ToList();

// DESPUÉS:
var badgesData = catalogo.Select(b => {
    var ganado = ganadosIds.FirstOrDefault(g => g.BadgeId == b.Id);
    return new {
        id           = b.Id,
        codigo       = b.Codigo,
        nombre       = b.Nombre,
        nivel        = b.Nivel,
        icono        = b.Icono,
        obtenido     = ganado != null,
        fechaObtenido = ganado?.FechaObtenido.ToString("dd/MM/yyyy"),
        otorgadoPor  = ganado?.OtorgadoPor,
        // "verificado" ya NO es manual — se controla desde el checkbox de cédula
        esManual     = b.Codigo == "creador_contenido"  // ← solo este queda manual
    };
}).ToList();
UX en el panel admin: El badge "verificado" debe aparecer en el panel de badges como read-only con un texto: "Este badge se otorga automáticamente al verificar la cédula profesional". No debe tener botones de otorgar/revocar.

Admin Panel — Sección Badges reordenada

Renderización del panel de badges en el admin — nueva lógica

La función JavaScript renderPanel(d) genera el HTML de los badges. Debe actualizar la sección de badges para reflejar las nuevas reglas:

// Dentro de renderPanel(d) — sección de badges:
const badgesHtml = (d.badges || []).map(b => {
    const icon  = b.obtenido
        ? `<i class="bi ${b.icono}" style="color:#22c55e"></i>`
        : `<i class="bi ${b.icono}" style="color:#d1d5db"></i>`;
    const fecha = b.obtenido ? `<small class="text-muted">${b.fechaObtenido}</small>` : '';
    const estadoLabel = b.obtenido
        ? `<span class="badge badge-ok">Obtenido</span>`
        : `<span class="badge badge-gray">Pendiente</span>`;

    // Badge "verificado" — read-only, controlado por cédula
    if (b.codigo === 'verificado') {
        return `<div class="d-flex align-items-center gap-2 py-2 border-bottom">
            ${icon} <span>${b.nombre}</span> ${estadoLabel} ${fecha}
            <small class="text-muted ms-auto">Se activa al verificar cédula</small>
        </div>`;
    }

    // Badges manuales (solo creador_contenido)
    if (b.esManual) {
        const btn = b.obtenido
            ? `<button class="btn btn-sm btn-outline-danger ms-auto" onclick="revocarBadge(${d.id},'${b.codigo}')">Revocar</button>`
            : `<button class="btn btn-sm btn-outline-success ms-auto" onclick="otorgarBadge(${d.id},'${b.codigo}')">Otorgar</button>`;
        return `<div class="d-flex align-items-center gap-2 py-2 border-bottom">
            ${icon} <span>${b.nombre}</span> ${estadoLabel} ${fecha} ${btn}
        </div>`;
    }

    // Badges automáticos — read-only
    return `<div class="d-flex align-items-center gap-2 py-2 border-bottom">
        ${icon} <span>${b.nombre}</span> ${estadoLabel} ${fecha}
        <small class="text-muted ms-auto">Automático</small>
    </div>`;
}).join('');
