### MutationObserver — Uso verificado

Dos `MutationObserver` presentes en layout:

1. **`mo`** — Observa elementos `.offcanvas` para limpiar inline `style.width/maxWidth`
2. **`observer`** — Observa `document.body` para limpiar `paddingRight > 40px`
3. **`bodyObserver`** — Observa adición de nuevos nodos offcanvas al body

Todos tienen `try/catch` para compatibilidad con browsers más antiguos. ✅

## E. Layout Shift — Análisis

El problema de layout shift por `paddingRight` de Bootstrap al abrir modales/offcanvas está mitigado por el `MutationObserver` en Script 2.

- Evento `show.bs.offcanvas` → `clearBodyPadding()`
- `shown.bs.offcanvas` → `clearBodyPadding()`
- `hidden.bs.offcanvas` → `clearBodyPadding()`
- MutationObserver como safety net ✅
