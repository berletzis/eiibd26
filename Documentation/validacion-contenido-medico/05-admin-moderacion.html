05 — Moderación Administrativa

Panel admin, estados, handler toggle e impacto en badges.

1. Ubicación en el panel admin

Página: Areas/Identity/Pages/Admin/DirectorioMedicos/Index.cshtml
Handler backend: Index.cshtml.cs

Cuando el admin abre el panel lateral de un médico (el drawer/offcanvas de detalle), se muestra una sección "Contenido Validado" que lista las validaciones de ese médico.

2. Query de carga en el panel

// En IndexModel — al abrir el drawer del médico:
var validaciones = await _context.ValidacionesContenidoProfesional
    .Where(v => v.ContenidoId == medicoId
             && v.TipoContenido == TipoContenidoValidado.PerfilMedico)
    .Include(v => v.ModeradoPor)
    .OrderByDescending(v => v.ActualizadoEn)
    .ToListAsync();

Se usa TipoContenido == PerfilMedico para filtrar solo las validaciones de perfil. El admin ve todas las validaciones sin importar el estado (sin filtro de estado).

4. Handler: OnPostCambiarEstadoValidacionAsync

Archivo: Areas/Identity/Pages/Admin/DirectorioMedicos/Index.cshtml.cs

public async Task<IActionResult> OnPostCambiarEstadoValidacionAsync(
    int validacionId,
    EstadoValidacion? nuevoEstado,
    string? nota)
{
    if (validacionId <= 0 || nuevoEstado is null)
        return BadRequest();

    var adminId = User.GetUserId();
    await _validacionService.CambiarEstadoAsync(
        validacionId, nuevoEstado.Value, adminId!, nota);

    TempData["AdminMsg"] = $"Estado cambiado a {nuevoEstado}.";
    return RedirectToPage();
}

El handler es no-destructivo: nunca borra el registro. Solo cambia Estado, ModeradoPorId, FechaModeracion y opcionalmente NotaModeracion.

5. Estados y su efecto

EstadoAcción admin disponibleBadge público
Validado Cambiar a EnRevision u Oculto Visible
EnRevision Reactivar (→ Validado) u Ocultar (→ Oculto) Oculto
Oculto Reactivar (→ Validado) o revisar (→ EnRevision) Oculto

6. Casos de uso de moderación

  • Datos incorrectos: Admin detecta que la especialidad declarada no coincide con la cédula → pone EnRevision → notifica al médico → médico actualiza → admin revalida.
  • Perfil abandonado: El médico dejó de operar → admin pone Oculto para no mostrar el badge de "validado por el profesional".
  • Error del médico: Médico validó por accidente un perfil incompleto → admin pone EnRevision temporalmente mientras el médico completa datos.
  • Reversión: Admin revierte EnRevision a Validado cuando el médico corrige el perfil.

7. Principio no-destructivo

Los registros de validación nunca se eliminan de BD. El campo NotaModeracion provee trazabilidad del motivo. FechaModeracion y ModeradoPorId permiten auditar quién y cuándo realizó el cambio.
