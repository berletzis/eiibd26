02 — Modelo Canónico

ValidacionContenidoProfesional y enums relacionados.

1. Enum: TipoContenidoValidado

Archivo: Models/Validacion/TipoContenidoValidado.cs

public enum TipoContenidoValidado : byte
{
    Termino      = 1,   // Términos del glosario médico
    Articulo     = 2,   // Artículos de Contenidos/Detalle
    PerfilMedico = 3    // Perfil de médico en el directorio ← NUEVO
}

Para PerfilMedico se usa TipoContenido = 3. Se almacena como TINYINT en SQL Server.

2. Enum: EstadoValidacion

public enum EstadoValidacion : byte
{
    Validado   = 1,   // Visible públicamente — estado inicial
    EnRevision = 2,   // Admin revisa — indicador oculto del público
    Oculto     = 3    // Admin ocultó — indicador oculto del público
}

Solo EstadoValidacion.Validado hace visible el badge en el perfil público. Los estados 2 y 3 ocultan el badge pero preservan el registro en BD.

3. Modelo: ValidacionContenidoProfesional

Archivo: Models/Validacion/ValidacionContenidoProfesional.cs
Tabla SQL: ValidacionesContenidoProfesional

[Table("ValidacionesContenidoProfesional")]
public class ValidacionContenidoProfesional
{
    public int Id { get; set; }

    [Required]
    public TipoContenidoValidado TipoContenido { get; set; }

    // Para PerfilMedico: ContenidoId = MedicoDirectorio.Id
    public int ContenidoId { get; set; }

    [Required][MaxLength(450)]
    public string UsuarioMedicoId { get; set; } = "";   // FK → AspNetUsers

    [MaxLength(800)]
    public string? Comentario { get; set; }             // Nota interna del médico (opcional)

    public EstadoValidacion Estado { get; set; } = EstadoValidacion.Validado;

    public DateTime CreadoEn { get; set; }
    public DateTime ActualizadoEn { get; set; }

    // Moderación (nullable — solo admin rellena)
    [MaxLength(450)]
    public string? ModeradoPorId { get; set; }          // FK → AspNetUsers (admin)
    public DateTime? FechaModeracion { get; set; }

    [MaxLength(500)]
    public string? NotaModeracion { get; set; }         // Razón del cambio de estado

    // Navegación
    public ApplicationUser? UsuarioMedico { get; set; }
    public ApplicationUser? ModeradoPor { get; set; }
}

4. Índice único en ApplicationDbContext

// En ApplicationDbContext.OnModelCreating:
modelBuilder.Entity<ValidacionContenidoProfesional>(e =>
{
    e.HasIndex(v => new { v.TipoContenido, v.ContenidoId, v.UsuarioMedicoId })
     .IsUnique()
     .HasDatabaseName("IX_ValidacionesContenido_Tipo_Contenido_Usuario");
});

Este índice garantiza que un médico tenga máximo una validación por perfil. El mismo índice cubre los casos Termino y Articulo.
