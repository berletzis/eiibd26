Reglas de uso

❌ NUNCA
  • Usar colores hardcodeados (#7c3aed, #764ba2, #6d28d9) — ya no existen en el sistema
  • Usar tokens del sistema viejo: --color-*, --space-*, --font-size-*, --se-*
  • Valores de espaciado arbitrarios como margin: 13px — usar la escala de 4px
  • Estilos inline en HTML para colores (style="color:#xxx") — usar token + clase utility
  • Crear nuevas clases CSS sin consultar si ya existe un token o utility
✅ SIEMPRE
  • Usar var(--eii-primary) para el color brand en CSS
  • Usar #6a4e7a (hex literal) en JS o atributos HTML que no soporten CSS vars
  • Usar rgba(106, 78, 122, x) cuando necesites transparencia del color primary
  • Combinar Bootstrap 5 con las clases eii-* — no reemplazar Bootstrap
  • Cargar eiibd-tokens.css primero, luego los demás CSS del sistema
ℹ️ EXCEPCIONES DOCUMENTADAS
  • Gradiente IA NINA: linear-gradient(135deg, #667eea 0%, #764ba2 100%) — identidad visual del asistente IA, preservado intencionalmente
  • Gradiente texto IA: linear-gradient(135deg, #7c3aed 0%, #6d28d9 100%) con -webkit-background-clip: text — solo en badge del toggle NINA
  • Botón .btn-generar-ia en Admin/Sintomas y Admin/Tratamientos — acción de IA, mantiene gradiente propio

Reglas del sistema editorial

  • Blog H1 y Termino H1 comparten exactamente el mismo selector: .eii-page-title
  • Ambos usan el wrapper .eii-page-header > .eii-page-header__content
  • Las H2 de secciones de Termino usan .editorial-section-h2 (NO inline styles)
  • Los pills de tipo usan clases BEM: .termino-tipo-pill--sintoma / --tratamiento
  • Todos los botones de comunidad usan .eii-btn (NO .btn-purple)
  • Thumbnails de sidebar usan .sidebar-thumb (NO inline style)
  • Aviso médico usa tokens: --eii-primary-soft, --eii-primary-border
  • Sidebar section title: font-weight: var(--eii-fw-semibold) — nunca 800
