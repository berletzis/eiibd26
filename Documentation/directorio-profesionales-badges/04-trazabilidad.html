FASE 3 — Trazabilidad de Badges (Audit Log)

Proyecto EIIBD · Directorio de Profesionales · Generado 2026-05-27

Problema que resuelve

Actualmente MedicoPerfilBadge solo registra el estado actual de badges ganados. Cuando se revoca un badge, la fila se elimina y no queda registro de cuándo, quién ni por qué se revocó. Esto hace imposible:

  • Auditar si un badge fue revocado por error y necesita restaurarse.
  • Mostrar al admin el historial completo de un profesional.
  • Detectar patrones sospechosos (ej. badge otorgado y revocado múltiples veces).
  • Saber si la ausencia de un badge es reciente o fue siempre así.

Decisión de diseño — tabla de historial separada

Opción A — Soft delete en MedicoPerfilBadge

Añadir Revocado, FechaRevocacion, RevocadoPor a la tabla existente.

+ Una sola tabla

– El índice único (MedicoId, BadgeId) impide re-otorgar el mismo badge después de revocar (requeriría incluir Revocado en el índice)

– Queries actuales necesitarían agregar WHERE Revocado=false en todos lados

– Rompe la semántica actual: "una fila = un badge activo"

Opción B — Tabla historial separada ✓ ELEGIDA

MedicoBadgeHistorial: registra cada evento de otorgamiento/revocación.

+ MedicoPerfilBadge no cambia — "una fila = badge activo"

+ Permite re-otorgar el mismo badge libremente

+ Historial completo con múltiples eventos por badge

+ Los queries existentes no cambian

– Una tabla más a mantener

Principio guía

MedicoPerfilBadge = estado actual (snapshot). MedicoBadgeHistorial = ledger de eventos. El snapshot se actualiza, el ledger solo crece.

Schema SQL — nueva tabla

-- Script: SQL/add-medico-badge-historial.sql
-- Ejecutar idempotente en producción

IF NOT EXISTS (
    SELECT 1 FROM sys.tables
    WHERE name = 'MedicoBadgeHistorial' AND schema_id = SCHEMA_ID('dbo')
)
BEGIN
    CREATE TABLE dbo.MedicoBadgeHistorial (
        Id           INT           IDENTITY(1,1) NOT NULL,
        MedicoId     INT           NOT NULL,
        BadgeId      INT           NOT NULL,
        Evento       NVARCHAR(20)  NOT NULL,   -- 'otorgado' | 'revocado'
        Actor        NVARCHAR(100) NOT NULL,   -- 'sistema', 'admin', email del admin, etc.
        Motivo       NVARCHAR(300) NULL,        -- razón legible (opcional)
        FechaEvento  DATETIME2     NOT NULL DEFAULT SYSUTCDATETIME(),

        CONSTRAINT PK_MedicoBadgeHistorial PRIMARY KEY (Id),
        CONSTRAINT FK_MBH_Medico FOREIGN KEY (MedicoId)
            REFERENCES dbo.MedicosDirectorio(Id) ON DELETE CASCADE,
        CONSTRAINT FK_MBH_Badge  FOREIGN KEY (BadgeId)
            REFERENCES dbo.MedicoBadge(Id) ON DELETE CASCADE,
        CONSTRAINT CK_MBH_Evento CHECK (Evento IN ('otorgado', 'revocado'))
    );

    CREATE INDEX IX_MedicoBadgeHistorial_MedicoId
        ON dbo.MedicoBadgeHistorial (MedicoId, FechaEvento DESC);

    CREATE INDEX IX_MedicoBadgeHistorial_BadgeId
        ON dbo.MedicoBadgeHistorial (BadgeId);

    PRINT 'Tabla MedicoBadgeHistorial creada.';
END
ELSE
    PRINT 'Tabla MedicoBadgeHistorial ya existe — sin cambios.';

public async Task<bool> OtorgarBadgeAsync(int medicoId, string codigo, string otorgadoPor, string? motivo = null)
{
    var badge = await _db.MedicosBadge.AsNoTracking()
        .FirstOrDefaultAsync(b => b.Codigo == codigo && b.Activo);
    if (badge is null) return false;

    var yaExiste = await _db.MedicosPerfilBadge
        .AnyAsync(pb => pb.MedicoId == medicoId && pb.BadgeId == badge.Id);
    if (yaExiste) return false;

    _db.MedicosPerfilBadge.Add(new MedicoPerfilBadge
    {
        MedicoId      = medicoId,
        BadgeId       = badge.Id,
        FechaObtenido = DateTime.UtcNow,
        OtorgadoPor   = otorgadoPor
    });

    // Registrar en historial
    _db.MedicosBadgeHistorial.Add(new MedicoBadgeHistorial
    {
        MedicoId    = medicoId,
        BadgeId     = badge.Id,
        Evento      = "otorgado",
        Actor       = otorgadoPor,
        Motivo      = motivo,
        FechaEvento = DateTime.UtcNow
    });

    await _db.SaveChangesAsync();
    return true;
}

Implementación — RevocarBadgeAsync actualizado

public async Task<bool> RevocarBadgeAsync(int medicoId, string codigo, string revocadoPor = "admin", string? motivo = null)
{
    var badge = await _db.MedicosBadge.AsNoTracking()
        .FirstOrDefaultAsync(b => b.Codigo == codigo);
    if (badge is null) return false;

    var entry = await _db.MedicosPerfilBadge
        .FirstOrDefaultAsync(pb => pb.MedicoId == medicoId && pb.BadgeId == badge.Id);
    if (entry is null) return false;

    _db.MedicosPerfilBadge.Remove(entry);

    // Registrar revocación en historial
    _db.MedicosBadgeHistorial.Add(new MedicoBadgeHistorial
    {
        MedicoId    = medicoId,
        BadgeId     = badge.Id,
        Evento      = "revocado",
        Actor       = revocadoPor,
        Motivo      = motivo,
        FechaEvento = DateTime.UtcNow
    });

    await _db.SaveChangesAsync();
    return true;
}

Implementación — GetHistorialAsync

public async Task<List<MedicoBadgeHistorialDto>> GetHistorialAsync(int medicoId)
{
    return await _db.MedicosBadgeHistorial
        .AsNoTracking()
        .Where(h => h.MedicoId == medicoId)
        .Join(_db.MedicosBadge, h => h.BadgeId, b => b.Id,
              (h, b) => new MedicoBadgeHistorialDto
              {
                  BadgeCodigo   = b.Codigo,
                  BadgeNombre   = b.Nombre,
                  Evento        = h.Evento,
                  Actor         = h.Actor,
                  Motivo        = h.Motivo,
                  FechaEvento   = h.FechaEvento
              })
        .OrderByDescending(h => h.FechaEvento)
        .ToListAsync();
}

public class MedicoBadgeHistorialDto
{
    public string BadgeCodigo { get; set; } = string.Empty;
    public string BadgeNombre { get; set; } = string.Empty;
    public string Evento      { get; set; } = string.Empty;  // "otorgado" | "revocado"
    public string Actor       { get; set; } = string.Empty;
    public string? Motivo     { get; set; }
    public DateTime FechaEvento { get; set; }
}

Cambio en IMedicoBadgeService — firma con motivo

Breaking change menor: La firma de RevocarBadgeAsync cambia de (int, string) a (int, string, string, string?). Los llamadores actuales en el admin usan RevocarBadgeAsync(id, "verificado") — al añadir parámetros opcionales, estos seguirán funcionando sin cambios de llamador.

Los llamadores en el admin que pasan solo 2 argumentos seguirán compilando porque revocadoPor y motivo tienen valor por defecto.
