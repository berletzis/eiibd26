6.2. Orden de Presentación

  1. Nombre del médico (H1 o nombre destacado)
  2. Especialidad / Subespecialidad (texto secundario)
  3. Badges primarios (una fila, flex-wrap, gap 6px)
  4. Badges secundarios (una fila separada, visualmente subordinada)
  5. Ubicación / Hospital
  6. Confirmaciones comunitarias
✅ BENEFICIOS DE ESTE LAYOUT:
  • Jerarquía visual clara: información crítica primero
  • Menor densidad: espaciado vertical entre secciones
  • Badges agrupados por importancia
  • Fácil escaneo: paciente identifica datos clave en 2-3 segundos

6.4. Especificación de Código para _MedicoBadges.cshtml

@model IEnumerable<eiibd26.Models.Medico.MedicoBadgeDto>

@{
    var primaryCodes = new[] { "perfil_reclamado", "verificado", "activo_comunidad" };
    var secondaryCodes = new[] { "participante_qa", "validador_contenido", "creador_contenido" };

    var primaries = Model?.Where(b => primaryCodes.Contains(b.Codigo)).ToList() ?? new();
    var secondaries = Model?.Where(b => secondaryCodes.Contains(b.Codigo)).ToList() ?? new();
}

<!-- Badges Primarios -->
@if (primaries.Any())
{
    <div class="medico-badges-primary d-flex flex-wrap gap-2 mb-2">
        @foreach (var badge in primaries)
        {
            var obtenido = badge.Obtenido;
            <span class="badge-medico-pill badge-primary @(obtenido ? "obtained" : "not-obtained")"
                  data-badge-code="@badge.Codigo"
                  title="@badge.Descripcion">
                <i class="bi @badge.Icono"></i>
                <span class="badge-label">@badge.Nombre</span>
            </span>
        }
    </div>
}

<!-- Badges Secundarios -->
@if (secondaries.Any(b => b.Obtenido))
{
    <div class="medico-badges-secondary d-flex flex-wrap gap-2">
        @foreach (var badge in secondaries.Where(b => b.Obtenido))
        {
            <span class="badge-medico-pill badge-secondary obtained"
                  data-badge-code="@badge.Codigo"
                  title="@badge.Descripcion">
                <i class="bi @badge.Icono"></i>
                <span class="badge-label">@badge.Nombre</span>
            </span>
        }
    </div>
}
