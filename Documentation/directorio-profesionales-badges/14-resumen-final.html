Test: Eliminación de Duplicados Semánticos

Objetivo: Validar que NO existen badges con la misma condición lógica renderizados múltiples veces.

test('no duplicate badges for same condition', async ({ page }) => {
  await page.goto('/DirectorioMedicos/Detalle/1');

  // Verificar que NO existen duplicados semánticos
  const perfilReclamado = await page.locator('.badge-medico-pill[data-badge-code="perfil_reclamado"]').count();
  const verificado = await page.locator('.badge-medico-pill[data-badge-code="verificado"]').count();
  const activoComunidad = await page.locator('.badge-medico-pill[data-badge-code="activo_comunidad"]').count();

  expect(perfilReclamado).toBeLessThanOrEqual(1); // Solo UNA instancia
  expect(verificado).toBeLessThanOrEqual(1);
  expect(activoComunidad).toBeLessThanOrEqual(1);

  // NO debe existir "Médico verificado" inline (era duplicado de perfil_reclamado)
  const medicoVerificadoInline = await page.locator('text="Médico verificado"').count();
  expect(medicoVerificadoInline).toBe(0);
});

Test: Jerarquía Visual (Primarios vs Secundarios)

Objetivo: Validar que badges primarios tienen mayor peso visual que secundarios.

test('primary badges have greater visual weight', async ({ page }) => {
  await page.goto('/DirectorioMedicos/Detalle/1');

  const primaryBadge = page.locator('.badge-medico-pill.badge-primary').first();
  const secondaryBadge = page.locator('.badge-medico-pill.badge-secondary').first();

  if (await secondaryBadge.count() > 0) {
    const primarySize = await primaryBadge.evaluate(el => parseFloat(window.getComputedStyle(el).fontSize));
    const secondarySize = await secondaryBadge.evaluate(el => parseFloat(window.getComputedStyle(el).fontSize));

    expect(primarySize).toBeGreaterThan(secondarySize);

    const primaryOpacity = await primaryBadge.evaluate(el => parseFloat(window.getComputedStyle(el).opacity));
    const secondaryOpacity = await secondaryBadge.evaluate(el => parseFloat(window.getComputedStyle(el).opacity));

    expect(primaryOpacity).toBeGreaterThan(secondaryOpacity);
  }
});

RESUMEN EJECUTIVO FINAL

✅ SIMPLIFICACIÓN COMPLETADA

La auditoría y propuesta de simplificación del sistema de badges del Directorio de Profesionales ha identificado y resuelto redundancias críticas, reducido sobrecarga cognitiva y establecido jerarquía visual clara.

Problemas Identificados

  1. Tres sistemas de badges operando simultáneamente (Sistema 1: catálogo DB, Sistema 2: inline duplicados, Sistema 3: contadores dinámicos)
  2. Redundancia semántica total: 3 badges para "verificación", 2 para "comunidad"
  3. Inconsistencia visual: outlined vs filled, tamaños distintos, íconos distintos
  4. Sobrecarga visual: hasta 9 badges en pantalla simultáneamente
  5. Nombres ambiguos: "Verificado", "Activo en Comunidad", "Médico verificado"

Soluciones Implementadas

  • Eliminado Sistema 2 completo (badges inline duplicados en Detalle.cshtml líneas 89-131)
  • Renombrados 2 badges: "Verificado" → "Cédula Verificada", "Activo en Comunidad" → "Validado por Pacientes"
  • Establecida jerarquía: 3 badges primarios (críticos) + 3 secundarios (complementarios)
  • Unificado patrón visual: outlined con fondo suave (consistente)
  • Reducida densidad: 2 filas espaciadas vs 3 filas apretadas
  • Clarificada semántica: nombres específicos y directos
