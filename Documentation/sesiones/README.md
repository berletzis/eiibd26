## 📋 Convenciones

### Nomenclatura de archivos
```
YYYY-nombre-descriptivo-kebab-case.md
```

Ejemplo: `2025-admin-directory-badges-confirmaciones.md`

### Estructura de cada sesión

Cada archivo de sesión debe incluir:
1. **Encabezado** con fecha, contexto, estado
2. **Objetivos de la sesión**
3. **Análisis inicial** (estado previo)
4. **Soluciones implementadas** (código, cambios)
5. **Impacto en el sistema**
6. **Casos de uso** (ejemplos prácticos)
7. **Documentación generada**
8. **Checklist de implementación**
9. **Código relevante** (snippets clave)
10. **Lecciones aprendidas**
11. **Próximos pasos sugeridos**
12. **Archivos modificados** (lista completa)

### Estado de sesiones

- ✅ **Completado** — Implementación terminada, compilando, documentada
- 🚧 **En progreso** — Trabajo activo
- ⏸️ **Pausado** — Bloqueado o pendiente de decisión
- ❌ **Cancelado** — Descartado
