# PWA Icons Required

Para que la PWA funcione correctamente, necesitas agregar los siguientes iconos en esta carpeta:

## Tamaños requeridos:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png (IMPORTANTE: usado para Android)
- icon-384x384.png
- icon-512x512.png (IMPORTANTE: usado para splash screen)

## Cómo generarlos:

### Opción 1: Online (Recomendado)
1. Ve a: https://www.pwabuilder.com/imageGenerator
2. Sube tu logo (mínimo 512x512px)
3. Descarga los iconos generados
4. Copia todos los archivos a esta carpeta

### Opción 2: Usar placeholder temporalmente
Si no tienes iconos aún, puedes usar un color sólido temporalmente.

### Nota:
Los iconos deben tener fondo sólido (no transparente) para Android.
Colores recomendados: #764ba2 (morado de EIIBD)
