4. Decisión Técnica Crítica — Librería PDF

⚠️ No hay ninguna librería PDF instalada actualmente en eiibd26.csproj.
LibreríaLicenciaProsContras
QuestPDF ⭐ Recomendado Comunitaria gratuita (< $1M USD ingresos) API fluente declarativa, tablas, secciones, header/footer nativos. La más limpia para este caso. Requiere declarar QuestPDF.Settings.License = LicenseType.Community
PdfSharpCore MIT (sin restricciones) Sin restricciones de licencia API de bajo nivel, más verbosa, sin layout automático
iText7 Community AGPL Muy completo AGPL puede ser restrictiva en producto comercial
Syncfusion Comercial / gratis comunidad Muy pulido Requiere licencia comercial en producción

Recomendación: QuestPDF — API declarativa por secciones, perfecta para header / bloques / footer numerados.
PackageReference a agregar: <PackageReference Include="QuestPDF" Version="2024.10.4" />

5. Riesgos Identificados

RiesgoSeveridadMitigación
Rangos de fechas grandes (6 meses × múltiples tablas) Media Proyectar solo columnas necesarias; límite configurable (ej. 500 registros por sección). Nota en el PDF si se truncó.
Licencia QuestPDF Baja Confirmar ingresos del producto. Alternativa: PdfSharpCore (MIT).
Usuario sin datos en el período Baja El DTO maneja listas vacías; el PDF genera secciones con "Sin registros en el período".
fechaInicio de síntomas/tratamientos vs rango temporal Media Decisión pendiente de validación: ¿filtrar por fechaInicio del registro del usuario, o por fecha del tracking (TrackingSintomaUsuario.Fecha)?
Zona horaria inconsistente en BD Baja Mostrar fechas tal como están en la DB sin conversiones, para no introducir inconsistencias.
Seguridad del endpoint de descarga Baja La nueva página usa [Authorize]. El userId se lee siempre de User.FindFirst(ClaimTypes.NameIdentifier), nunca de un parámetro HTTP.

6. Posibles Cuellos de Botella

  • TrackingSintomaUsuario puede crecer rápido si el usuario registra seguimiento diario. Con 6 meses: ~180 registros por síntoma. Mitigación: .Take(limit) configurable.
  • Generación del PDF en memoria es síncrona en QuestPDF. Para documentos >5 páginas densas puede sentirse lento. En fase actual no requiere background; se puede añadir después si es necesario.
