## 📖 USAGE FLOW

### End-to-End Process

```
1. USER CREATES QUESTION
   ↓
2. SAVED TO DATABASE (immediate)
   ↓
3. RESPONSE 200 OK (user doesn't wait)
   ↓
4. [BACKGROUND] Job enqueued
   ↓
5. [BACKGROUND] Hangfire picks up job
   ↓
6. [BACKGROUND] Check if AI needed
   ↓
7. [BACKGROUND] Generate AI answer (5-10s)
   ↓
8. [BACKGROUND] Validate safety
   ↓
9. [BACKGROUND] Add disclaimer
   ↓
10. [BACKGROUND] Save to database
   ↓
11. USER REFRESHES PAGE → sees answer
```

### Skip Conditions

**AI generation is skipped if:**
- Question already has AI answer (`TieneRespuestaIA = true`)
- Question has human answers (`COUNT(Respuestas WHERE EsIA = false) > 0`)
- AI service is disabled (`Enabled = false` in config)
